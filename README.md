# AA Music HUD
Trình phát nhạc cho Android Auto, hiển thị tốc độ, giới hạn tốc độ và cảnh báo camera lên thẻ media.

## Build
1. Mở thư mục này bằng Android Studio (Koala trở lên, JDK 17), chờ Gradle sync.
2. Build > Build APK, cài vào điện thoại.

## Dùng
1. Mở app, bấm "Cấp quyền" (vị trí, nhạc, thông báo).
2. (Tuỳ chọn) nhập radio online, mỗi dòng `Tên|URL`, bấm "Lưu".
3. Bấm "Bắt đầu dịch vụ".
4. Android Auto: bật Developer settings > Unknown sources (hoặc cài qua AAXLU/KingInstaller như bạn đang dùng).
5. Trên xe, mở "AA Music HUD" từ danh sách media, chọn bài.
